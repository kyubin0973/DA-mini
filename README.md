# ESS 배터리 수명 예측

초기 100사이클의 측정 데이터만으로 리튬이온 배터리 셀의 총 수명(cycle life)을 예측한다.
배터리 교체 비용은 ESS CAPEX의 30\~40%를 차지하므로, 수명을 초기에 알 수 있으면 교체 시점을 미리 계획하고 셀을 선별할 수 있다.

**결과 요약**

- 모델은 `log10 Var(ΔQ)` 피처 하나를 쓰는 선형 회귀다. 피처와 모델은 EDA 결과에서 정했고, Batch 1 안의 교차검증으로 확정했다.
- Test(Batch 2) MAPE는 <b>26.66%</b>로 원 논문의 9.1%에 미치지 못한다. 같은 배치 안의 Hold-out에서는 8.71%, 시험 조건이 비슷한 Batch 3에서는 12.50%다.
- Test 오차의 대부분은 Batch 2 일반 30셀의 과대예측(편향 +29.15%)이다. 이 집단은 휴지 시간이 학습 배치와 다르며, EDA 단계에서 약 31%의 과대예측을 미리 예상했다.
- 학습 배치에 시험 조건의 변동이 없어 Batch 1만으로는 이 편향을 줄일 수 없다.

표와 그림을 포함한 자세한 근거는 [README_LONG.md](README_LONG.md)에 있다.


## 프로젝트 개요

- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12) — 분석 대상 36셀, 수명 534\~1,074
- 평가 데이터 : Batch 2 (2018-02-20) — 39셀, 수명 392\~1,186 / 추가 평가 Batch 3 (2018-04-12) — 44셀, 수명 541\~1,935
- 태스크 : Regression (Cycle Life 예측), 타깃은 `log10(cycle_life)`, 지표는 MAPE

분석 대상은 수명 값이 있고 마지막 방전 용량이 EOL(0.88Ah)에 도달한 것을 데이터로 확인한 셀이다.

## EDA

전체 과정과 수치는 [notebooks/01_EDA.ipynb](notebooks/01_EDA.ipynb)에 있다.

- **데이터 정제**
  - Batch 1의 46셀 중 10셀은 EOL에 도달하지 않은 채 시험이 끝났고, 기록된 `cycle_life`가 측정 사이클 수 + 1과 같았다. 방전 용량의 측정 오류 70행도 제외했다.
  - 핵심 발견 : **제공된 수명 값을 그대로 쓸 수 없다. 검증을 통과한 분석 대상은 119셀이다.**

- **Cycle Life 분포**
  - 중앙값이 772.5 / 472 / 1,005.5로 배치마다 다르다. 단수명(<500)은 Batch 2에만 28셀, 장수명(>1,000)은 5 / 3 / 23셀이다.
  - Batch 2는 일반 30셀(392\~514)과 `newstructure` 9셀(777\~1,186)의 혼합이다.
  - 핵심 발견 : **평가 배치의 일반 30셀은 전부 학습 배치의 수명 범위 밖에 있다.** 550사이클 미만인 셀이 Batch 1에 1개뿐이어서 분류는 학습할 수 없다.

- **열화 곡선 분석**
  - 장수명 vs 단수명 : 단수명 셀은 knee 이전 열화 속도가 약 2배(0.107 / 0.055mAh/사이클), 이후가 약 2.4배 빠르다.
  - knee는 수명의 약 70% 지점에 있고(가장 이른 것이 243사이클), 이후 열화가 9\~11배 빨라진다.
  - 핵심 발견 : **초기 100사이클의 용량 값에는 수명 신호가 없다.** 이 구간의 용량 변화는 사이클 간 변동 수준이다.

- **ΔQ(V) 곡선 분석**

  ![ΔQ 분산과 수명](results/figures/q3_var_vs_life.png)

  - ΔQ(V) = Q₁₀₀(V) − Q₁₀(V). 수명이 짧은 셀일수록 곡선이 깊게 파인다.
  - `log10 Var(ΔQ)`와 `log10(수명)`의 상관이 −0.84 / −0.38(Batch 2 일반) / −0.76이다.
  - 핵심 발견 : **`log Var(ΔQ)`가 수명과 가장 강하게 연관되지만 집단에 따라 직선의 위치가 다르다.** Batch 2 일반 셀은 Batch 1 직선 예측의 약 76%여서, 약 31% 과대예측을 예상했다. 이 집단은 휴지 시간이 약 5분으로 Batch 1(약 1분)과 다르다.

- **충전 속도(C-rate)와 수명의 관계**
  - 평균 충전 속도가 다양한 것은 Batch 1뿐이다(4.00\~5.40C). 나머지는 4.79\~4.81C로 고정이다.
  - Batch 1에서 상관은 −0.59이고, 가장 빠른 두 셀을 빼면 −0.45다.
  - 핵심 발견 : **"고속 충전 셀이 수명이 짧다"는 Batch 1 안에서만 확인된다.** 평가 배치에서는 충전 조건으로 셀을 구분할 수 없다.

- **상관관계와 다중공선성**
  - 피처 16개를 세 기준(학습 배치 상관, 다른 집단 안의 방향, 집단 사이의 관계)으로 판정했다. ΔQ 피처끼리는 상관이 0.98\~1.00이다.
  - 핵심 발견 : **세 기준을 모두 통과한 것은 ΔQ 피처뿐이고, 그중 하나만 쓰면 된다.**


## Modeling

전체 과정은 [02_feature_engineering.ipynb](notebooks/02_feature_engineering.ipynb), [03_modeling.ipynb](notebooks/03_modeling.ipynb)에 있다.

### 피처 엔지니어링 전략

| 피처 | 판정 | 근거 |
|---|---|---|
| `log_var` = log10 Var(Q₁₀₀ − Q₁₀) | **채택** | 수명과의 상관이 가장 강하고(−0.84) 세 집단에서 방향이 같다 |
| `qd_slope_last` (91\~100사이클 용량 기울기) | 후보 → 제외 | 교차검증 MAPE가 9.46% → 10.19%로 나빠졌다 |
| 다른 ΔQ 통계, 용량, 충전 조건, 온도, 내부 저항 | 제외 | 같은 정보이거나, 집단마다 방향이 다르거나, 측정 오류와 결측이 있다 |

정제와 피처 계산은 `src/`의 함수로 만들었고, 결과가 EDA 값과 119셀 모두 일치한다.

### 모델 선택 및 근거

- 후보 모델 : 선형 회귀, Ridge, LASSO × 피처 구성 2가지
- 최종 모델 : **`log_var` 선형 회귀** (`log_life = −0.296 × log_var + 1.760`)
- 데이터 분할 : 충전 정책 단위로 Train 27셀 / Hold-out 9셀. 같은 정책의 셀이 양쪽에 나뉘지 않는다. 교차검증도 정책 단위 GroupKFold(5).
- 선택 이유 :
  - **교차검증 MAPE가 9.46%로 가장 낮고 가장 단순하다.** 두 번째 피처를 넣으면 학습 폴드는 좋아지고(7.83 → 7.66) 검증 폴드는 나빠진다(9.46 → 10.19). Ridge·LASSO로도 나아지지 않았다.
  - **학습 범위 밖을 예측할 수 있다.** 수명이 짧은 7셀을 빼고 학습해 그 셀을 예측하면 선형 회귀 12.4%, Random Forest 22.6%, XGBoost 24.9%다. 트리 계열은 학습 범위의 최솟값(702) 아래를 예측하지 못했다(예측 최소 715, 731).


## 성능 결과

| 구분 | | MAPE (%) | 비고 |
|---|---|---:|---|
| Train (Batch 1 CV) | | 9.46 | Train 27셀, 정책 단위 GroupKFold(5) |
| Valid (Batch 1 Hold-out) | | 8.71 | 정책 단위로 분리한 9셀 |
| Test (Batch 2) | | **26.66** | 39셀 |
| | Gap (Train-Valid) | +0.75 | Valid의 오차가 더 작다. 과적합 신호 없음 |
| | Gap (Valid-Test) | −17.96 | Test의 오차가 17.96%p 크다. 배치 간 일반화 저하 |
| | Gap (Target-Test) | −17.56 | Target : 원논문 9.1% |
| Test (Batch 3) | | 12.50 | 44셀 (추가 평가) |
| | Gap (Batch2-Batch3) | +14.17 | Batch 2의 오차가 14.17%p 크다 |
| | Gap (Target-Test) | −3.40 | Batch 3 기준 |

Gap은 표기한 순서대로 뺀 값이다. MAPE는 낮을수록 좋으므로 Gap (Valid-Test)와 Gap (Target-Test)는 음수일 때 Test가 더 나쁘다는 뜻이다.

![예측과 실제](results/figures/m2_pred_vs_actual.png)

| 평가 대상 | 셀 | MAPE | 편향 | 편향 제거 후 MAPE |
|---|---:|---:|---:|---:|
| Valid (Batch 1 Hold-out) | 9 | 8.71% | −7.65% | 7.74% |
| Batch 2 일반 | 30 | 29.86% | +29.15% | 8.23% |
| Batch 2 `newstructure` | 9 | 16.01% | +12.46% | 13.93% |
| Batch 3 | 44 | 12.50% | −1.55% | 12.86% |

편향은 집단 전체가 치우친 정도(양수이면 과대예측)다. 편향 제거 후 MAPE는 평가 배치의 실제 수명으로 계산하므로 모델의 성능이 아니라 오차의 원인을 나누어 보기 위한 값이다.

### Gap 해석

- **Gap (Train-Valid) +0.75** : 폴드 간 표준편차(1.9) 안이다. 과적합의 신호는 없다.
- **Gap (Valid-Test) −17.96** : Batch 2 일반 30셀의 편향(+29.15%)에서 온다. 39셀 중 37셀을 과대예측했다. 이 집단은 휴지 시간이 약 5분으로 학습 배치(약 1분)와 다르고, EDA에서 예상한 약 31%와 2%p 차이다.
- **Gap (Batch2-Batch3) +14.17** : 피처가 학습 배치에 과적합된 것은 아니다. 학습에 쓰지 않은 Batch 3에서 편향이 −1.55%다. 차이는 조건이 다른 Batch 2 일반 셀에서만 나온다. Batch 3의 오차는 치우침이 아니라 흩어짐이고, 학습 범위를 넘는 장수명 구간(1,074 초과 16셀, 18.10%)에서 커진다.
- **Gap (Target-Test) −17.56** : 원 논문(본문 Table 1, Methods 기준)과 두 가지가 다르다.
  - 9.1%는 피처 9개 모델의 값이다. 피처 1개 모델은 논문에서도 11.4\~14.7%다.
  - 논문은 휴지 1분인 배치와 5분인 배치를 합쳐 절반씩 학습·평가로 나눴다. 이 과제는 휴지 1분인 배치만으로 학습한다.
  - Batch 3으로 비교하면 논문의 같은 모델이 11.4%, 이 프로젝트가 12.50%다. 논문은 잡음이 큰 셀을 제외한 40셀, 이 프로젝트는 44셀이다.


## 오류 분석

**모델이 가장 크게 틀린 셀의 공통점**

- Batch 2 일반 : 오차 60% 안팎인 3셀(b2c6, b2c18, b2c15)은 `log_var`가 집단 안에서 낮은 쪽이다. 오차와 `log_var`의 상관이 −0.72다. 이 집단 안의 기울기는 −0.081로 모델(−0.296)보다 훨씬 완만하다. `log_var`가 달라도 수명이 거의 달라지지 않는다.
- Batch 3 : 수명이 긴 셀을 과소예측한다. 가장 긴 셀(1,935)을 1,110으로 예측했다. Hold-out에서도 수명 788 이상인 5셀이 전부 −9\~−18%였다.

**원인 가설**

- 시험 조건(휴지 시간)의 차이. 다만 휴지 시간이 원인인지는 이 데이터로 확인할 수 없다.
- 장수명 구간의 학습 부족. 가장 느린 충전 정책의 5셀이 EOL 미도달로 제외되어 학습 범위의 최대가 1,074다.

**DAY 1의 예상과 실제**

| DAY 1의 예상 | 결과 |
|---|---|
| Batch 2 일반 셀에서 약 31% 과대예측 | 맞음 (+29.15%) |
| Batch 3은 편향이 거의 없음 | 맞음 (−1.55%) |
| 트리 계열은 학습 범위 밖을 예측하지 못함 | 맞음 |
| Batch 2 일반 셀은 기울기가 같고 평행하게 이동 | **틀림** (집단 안의 기울기 −0.081) |

마지막 항목은 EDA의 해석 오류다. 근거로 쓴 기울기가 일반 30셀과 `newstructure` 9셀을 합쳐 구한 값이었다.

**개선 방향 — 추가 실험 (Test 성능 아님)**

Batch 2 일반 셀 중 k개의 수명을 알 때 그것으로 편향을 보정하면(1,000회 반복 평균) 3개로 29.86% → 9.82%, 5개로 9.24%가 된다. 그러나 모델 없이 그 셀들의 평균 수명만 써도 7.42%로 더 낫다. 이 집단은 수명 범위가 좁기 때문이다. 모델이 의미를 갖는 것은 수명이 넓게 퍼진 경우(Batch 3, 12.50%)다. 이 실험은 Batch 2의 수명 일부를 썼고 Test 평가 후에 추가했다.


## ESS 도메인 해석

**실제 BESS에 적용한다면**

- 셀 선별과 교체 일정 : 입력은 10번째와 100번째 사이클의 방전 곡선 두 개다. 운전 조건이 학습 데이터와 같으면 초기 100사이클 시점에 수명을 약 9% 오차로 추정한다.
- 용량 모니터링의 보완 : 급격한 열화는 수명의 약 70% 지점에서 시작되고 그 전까지 용량은 거의 변하지 않는다. 용량으로는 미리 알 수 없는 것을 초기 방전 곡선의 변화로 추정한다.

**한계와 실 배포에 필요한 것**

- 운전 조건이 다르면 그대로 쓸 수 없다. 약 29% 과대예측은 교체 시점을 늦게 잡는 방향이어서 위험한 쪽의 오차다.
- 조건이 다양한 학습 데이터가 필요하다. 대상 조건의 셀이 학습에 포함되거나, 그 조건의 셀 3\~5개를 수명 끝까지 시험해 보정해야 한다.
- 학습 범위(최대 1,074사이클)를 넘는 장수명 셀을 과소예측한다.
- 학습 셀이 36개이고, 30도 챔버에서 완전 충방전을 반복한 실험실 데이터다.
